# 戰士對護衛與法師：單職業通關候選

授權：使用者要求實作單職業通關測試，並將遊戲介面與說明改為中文。
依據：GAME_PLAN 第 4、9、20 節；保留每輪一名角色。沒有將產品改為多人隊伍。

## 候選規則

- 戰士生命 12；護衛、法師各 6。固定低骰 3 起始，基本傷害 2。
- 每回合累積移動 240，移動後最多一次攻擊或格擋；攻擊後不能移動。
- 護衛預告紅色揮擊區，造成 2 傷害；蓄力原點位移超過 80 可打斷。
- 法師奇數回合預告紫色法術區，造成 3 傷害；偶數回合恢復，不攻擊。
- 藍色區域是法術掩體，不是實體阻擋物；只免除法術傷害，護衛仍可攻擊區內角色。
- 基本盾擊與衝鋒命中蓄力法師即可打斷；高骰震波命中法師也會打斷，不依賴高骰。
- 衝鋒使用後下一回合冷卻，再下一回合可用；盾擊無冷卻。
- 格擋消耗本回合攻擊，當次敵人回應每個敵人的傷害減少 2，下一回合清除。
- 戰場為連續安全地面；本關不以深坑或拆橋作主要解法。舊物理／地形／战術實驗室保留。
- 介面、角色標籤、提示、視窗標題、測試包說明為繁體中文；Windows 使用系統中文字型。
- 沒有完整隨機 D20、命運值、法師／盜賊玩家角色、裝備、地圖、存檔、壓力或隊伍系統。

## 驗證問題

1. 固定低骰、普通起始設定，突進打斷與掩體等待是否都能通關？
2. 玩家能否理解掩體只擋法術，格擋則減少敵人傷害？
3. 衝鋒冷卻與法師恢復期是否促使玩家改用不同技能或位置？

整合測試必須以合法移動、攻擊與格擋完成兩條通關路線，不能注入敵人死亡、高骰或玩家傳送來證明可通關。
程式測試不等同真人覺得好玩；G1/G2/G3 仍待使用者驗收。本候選不合併、不發布。
