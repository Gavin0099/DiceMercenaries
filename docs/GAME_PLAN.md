# DiceMercenaries — 完整開發計畫 v0.1

- **日期**：2026-10-13
- **中文暫定名**：骰子傭兵團
- **英文暫定名**：Dice Mercenaries
- **GitHub repository**：`DiceMercenaries`（建議私有倉庫起步；尚未建立）
- **產品類型**：單人、回合制、D20 職業物理戰鬥 Roguelite
- **首發目標**：Windows / Steam；後續視控制器與觸控測試考慮 Steam Deck、iPad
- **引擎**：Godot 4.7.2 stable + typed GDScript；2D 橫向戰場，桌遊模型質感
- **狀態**：設計提案／尚未實作。與 `TacticalGo`、`WastelandChronicles` 完全獨立；不改動原有 repo。

> **一句話玩法**：每次選擇一名奇幻職業進入分岔地下城，擲 D20 決定職業招式的發揮程度，親手瞄準、擊退敵人、破壞地形，利用當輪取得的骰印與裝備組出不同流派。失敗後保留公會等級與解鎖進度，再次冒險。

## 1. 產品願景與成敗假設

### 1.1 三大支柱

1. **職業差異是打法差異**：戰士靠撞擊、法師靠爆破與元素、盜賊靠反彈／鉤索，不是單純換造型或傷害倍率。
2. **骰子製造決策，不取消操作**：先看到 D20 再決定如何出招與瞄準；基本攻擊永遠可用，沒有攻擊後再擲命中骰的雙重失敗。
3. **物理地形創造故事**：一記攻擊可以撞牆、連鎖爆炸、切斷平台或讓敵人墜落；失手有可理解的後果，而非任意隨機懲罰。

### 1.2 Roguelite 的第四支柱

- 分岔節點路線讓玩家衡量**當前血量、職業構築、地形風險與獎勵**。
- 每輪裝備重置、共用公會等級永久保留；解鎖**更多選項**，而不是無限制提高基礎數值。
- 地下城主（DM）是**可預告的環境事件系統**，不是第一版的第二名玩家或生成式 AI。

### 1.3 明確不做

- 不做 D&D 正式規則重製；D20 是靈感，不複製專有文字、怪物設計、標誌或素材。
- 不做《百戰天蟲》原作的角色、音效、招式、美術複製。
- 不做多人連線、PvP、任意像素挖地、完整開放世界、職業獨立練等、永久刷神裝。
- 不因設計漂亮就提前做大量劇情、美術、語音；先驗證操作核心。

### 1.4 目前假設（不是已經證明）

| 假設 | 必須怎麼驗證 |
|---|---|
| D20 + 物理瞄準相乘，而非互相干擾 | 強制骰點 3 / 10 / 17 / 20，觀察玩家策略是否改變且仍可靠操作取勝 |
| 同職業至少有兩種有效流派 | 固定角色與地圖，更換兩套裝備後，觀察目標選擇與瞄準方式是否明顯不同 |
| 路線分岔值得思考 | 提供相同獎勵等級但不同地形／風險，看玩家會否依當輪裝備選路 |
| DM 事件增加決策，不只是噁心玩家 | 事件提前一回合預告、提供可達安全區；測試玩家能否解釋失敗原因 |
| PC 是最佳首發平台 | 先用鍵鼠驗證；之後用控制器與觸控真機試玩，不能只用模擬器判定 |

## 2. 遊戲循環與遊玩節奏

### 2.1 場外：傭兵公會

1. 查看**公會共用等級**、藍圖與成就。
2. 選擇**一名**職業出發；整輪不換人。
3. 從已解鎖的平衡起始武器、起始骰印中擇一配置（初始等級可以僅有固定配裝）。
4. 選擇章節、難度，生成本輪 `run_seed`。

### 2.2 場內：冒險地圖與戰鬥

1. 在 Slay the Spire 式的**有向分岔地圖**選下一個可達節點。
2. 選擇戰鬥、菁英、事件、商人、營地、寶物或 Boss。
3. 戰鬥以回合進行：敵人意圖及 DM 威脅可見 → 擲 D20 → 移動、選招、手動瞄準 → 物理結算 → 敵人／事件回應。
4. 戰後三選一獎勵，替換或強化當輪裝備，逐漸形成流派。
5. 擊敗 Boss 結算通關；死亡或放棄則結算獲得的公會經驗並結束當輪。

### 2.3 長度目標（未經實測）

- **P0 戰鬥玩具**：單場約 2–5 分鐘，目的是驗證操作。
- **P1 可玩試煉**：3 場戰鬥 + 1 次選路／獎勵 + Boss，期望約 10–15 分鐘。
- **首個完整章節**：約 6–8 個節點、1 個 Boss，期望單輪 20–35 分鐘；以真人試玩結果調整。

## 3. 戰鬥規則 v0.1（候選合約）

### 3.1 回合流程

1. 顯示敵人的下次攻擊意圖、DM 事件及危險區域。
2. **擲一顆公平 D20**，顯示原始點數與生效後的點數。
3. 玩家可消耗已累積命運值修正骰點，然後選擇招式。
4. 玩家可在移動範圍內站位（首版移動後攻擊，不允許攻擊後任意移動）。
5. 以鍵鼠選擇發射角度與力量，顯示可理解的**部分彈道預覽**，釋放一次攻擊。
6. 結算命中、傷害、擊退、物件碰撞、平台破壞、連鎖效果。
7. 敵人依預告的意圖執行行動；若 DM 事件到期則結算，轉下一回合。

**固定原則**：不因骰點低而失去基本移動、基本攻擊；D20 不再另行檢定命中。若玩家物理上射空，屬於可學習的操作結果。

### 3.2 D20 階級表

| 原始／生效骰點 | 機率（公平 D20） | 效果 |
|---|---:|---|
| 原始 1–5；未提升到其他階級 | 25% | 基本招式；回合結束時獲得 1 點命運值 |
| 生效 6–14 | 45%（無修正時） | 強化招式，增強位移、爆破或精準效果 |
| 生效 15–20 且非自然 20 | 25%（無修正時為 15–19） | 啟動職業特技；帶來新戰術可能 |
| **原始自然 20** | **5%** | 傳奇效果；華麗但不得破壞遊戲平衡 |

- `raw_roll` 是 D20 實際擲出的 1–20；`effective_roll` 是套用修正、限制 1–20 的結果。
- 自然 20 **只能由 `raw_roll == 20` 觸發**；改成 20、反轉成 20 都不是自然 20。
- 低骰獲得命運值依**原始**骰點判定，於**回合結束**時發放，避免當回合無成本立刻轉高階。
- 先暫定命運值上限 2；每回合最多消耗 1 點，讓 `effective_roll +3`，不可能藉此製造自然 20。
- D20 的高階效果優先增加**用途與物理可能性**，不做 3 倍、5 倍的直接傷害倍率。
- 裝備必須標示採 `raw_roll` 或 `effective_roll`，禁止含糊的「骰到高點」定義。

### 3.3 初版數值假設（僅供灰盒測試）

| 項目 | 候選值／限制 |
|---|---|
| 玩家生命 | 12 HP |
| 一般敵人 | 4–6 HP |
| 菁英敵人 | 8–10 HP |
| 基本命中傷害 | 約 2 HP；職業主差異在擊退／爆破／反彈 |
| 高骰附加傷害 | 每次攻擊附加直接傷害原則上不超過 +1；主要增加效果 |
| 物理撞擊 | 額外傷害有明確上限與冷卻，不允許同一目標無限彈傷 |
| 一般敵人跌落危險深坑 | 可直接被擊敗；Boss 則觸發特別受創／失衡，不因單次推落直接跳過全部機制 |
| 玩家的深坑 | 明確標示高風險；普通新手場先以低處平台代替一擊即死深坑 |

上述數值不是平衡定案。優先驗證「受傷／死亡原因看得懂」與「位置比純骰點更重要」。

### 3.4 彈道與移動操作

- `A/D` 或方向鍵：水平移動；空白鍵：跳躍／越障（若該職業允許），首版可只做平面移動。
- 滑鼠指向／拖曳：顯示預計發射方向與力量，釋放發射；`Esc` 可取消瞄準。
- 彈道預覽顯示**前段可預測路徑**，清楚標註風場等修正，不保證所有反彈最終落點。
- 武器攻擊必須有**可辨識的出手、命中、擊退、落地**回饋與適度停頓。
- 戰鬥資訊：D20、原始/生效值、招式階級、敵方意圖、危險區與裝備觸發，都必須在同屏或一鍵資訊層可見。

## 4. 職業與傷害技巧

| 職業 | 基本攻擊 | 6–14 | 15–19 | 自然 20 | 物理主軸 |
|---|---|---|---|---|---|
| 戰士 | 定向戰槌衝擊／短距離飛錘 | 較強擊退 | 撞牆／撞敵產生震波 | 強化群體衝擊 | 撞擊、推落、破壞掩體 |
| 法師 | 拋物線火球 | 小幅擴大爆炸 | 可引爆特定環境物件或造成二次效果 | 特殊連鎖爆破 | 範圍、爆炸、地形改造 |
| 盜賊 | 可瞄準的弩箭 | 精準與反彈強化 | 命中弱點／反彈後追加效果 | 特色機動連擊 | 反彈、角度、鉤索與背刺 |

### 4.1 首個原型角色

- **戰士**：不能只做貼臉平砍，必須具備可瞄準的定向衝擊或拋射飛錘，才有與百戰天蟲式瞄準互動的價值。
- **法師**：基本火球穩定可用；高骰主要讓火球能處理更多場景物件，不只更大傷害數字。
- **盜賊**：暫緩到核心成立再做；反彈幾何、鉤索和弱點系統較複雜，避免 P0 範圍膨脹。

### 4.2 流派組合（首版候選）

| 流派 | 裝備組合方向 | 需要改變的玩家行為 |
|---|---|---|
| 戰士：破城流 | 重錘 + 衝擊骰印 + 撞牆遺物 | 找牆／懸崖角度，不再只瞄敵人中心 |
| 戰士：低骰反擊流 | 盾系武器 + 低骰骰印 + 反震防具 | 願意承擔小傷，布局敵人的攻擊落點 |
| 法師：連鎖爆破流 | 爆炎法杖 + 引信遺物 + 擴散骰印 | 優先尋找地形物件與爆炸物位置 |
| 法師：冰面控制流 | 寒霜法杖 + 滑行遺物 | 利用坡度和冰面讓敵人跌落／滑入陷阱 |
| 盜賊：反彈狙擊流 | 機關弩 + 反彈遺物 | 尋找掩體後的反射角度 |
| 盜賊：鉤索機動流 | 鉤索器 + 弱點骰印 | 搶位置、從側翼或背後攻擊 |

**流派驗收**：同一張戰場切換兩套構築，應能觀察到不同的站位、瞄準目標或優先擊破物件；只有 DPS 改變不算通過。

## 5. 地形、物理與地下城主（DM）

### 5.1 地形層級

1. **不可破壞地形**：主地面、邊界；保證戰鬥可解且相機可控。
2. **可破壞模組**：橋梁、薄牆、支柱、掩體；具 HP、破壞狀態與新碰撞形狀。
3. **互動物件**：炸藥桶、滾石、可推動箱子；有明確觸發與影響範圍。
4. **危險地形**：落坑、岩漿、風場；必須在畫面上辨識清楚。

不使用第一版任意像素刪除與動態重建任意形狀碰撞；先做「固定模組被打碎後切換場景與碰撞」以控制效能與 Bug。

### 5.2 DM 事件契約

- DM 是**規則驅動的環境導演**：選事件、標示影響範圍、計時、結算；不實作真人地下城主 PvP。
- 事件必須至少提供**一個完整玩家回合的預警**。
- 不能毫無預警直接造成角色死亡；正常難度應存在合法逃避或利用事件的可能。
- 首版可在第 2 回合預告、第 3 回合結束時觸發；實際頻率由測試決定。
- 事件可被玩家利用，不必全部是懲罰；例如提前炸斷橋讓敵人掉下去。

| 事件 | 預警 | 玩家可採取的對策 | 導入階段 |
|---|---|---|---|
| 崩塌平台 | 高亮即將裂開的平台 | 移走、推敵上去、提前炸毀 | P0 |
| 滾石 | 顯示滾石起點與路徑 | 躲避、讓滾石撞敵人 | P1 |
| 魔法側風 | 顯示方向／強度及影響回合 | 改變瞄準或站位、曲射 | 後續 |

### 5.3 防止連鎖爆炸失控

- 每次攻擊附有 `attack_id`；同一遺物對同一 `attack_id` 的特殊觸發有次數限制。
- 二次爆炸、撞擊、反彈都設深度上限；不允許遺物 A → B → A 無限觸發。
- 傷害計算由規則層控制；物理系統輸出命中／碰撞事實，不直接相互遞迴扣血。
- 即使物理引擎在不同裝置細節不同，至少保證不重複擊殺、不卡住結算、不造成不受控的事件遞迴。

## 6. Slay the Spire 式分岔冒險地圖

### 6.1 章節規格

- 首個章節：**崩塌礦坑**（原創世界觀暫定名）。
- 每次產生一個有向、向上前進的節點圖：起點 → 約 5–7 層 → Boss。
- 節點顯示類型、預期獎勵層級、地形情報（深坑／爆炸桶／斷橋／風場等），**不需要完全揭露敵人位置**。
- 只能前往與當前位置相連的下一層節點，不能任意跳圖。
- 路線以事先設計的有效拓樸模板加少量隨機化起步，等 QA 覆蓋足夠再做更自由的圖生成。

### 6.2 節點類型

| 節點 | 玩法與獎勵 | 決策點 |
|---|---|---|
| 一般戰鬥 | 金幣、三選一獎勵 | 當輪構築是否適合這塊戰場 |
| 菁英戰 | 稀有骰印／遺物 | 以生命與風險換強化 |
| 寶物房 | 裝備、遺物或替換 | 是否轉流派 |
| 事件 | 情境選項、D20 檢定與明示風險 | 風險接受度與職業專長 |
| 商人 | 金幣購物、替換裝備 | 經濟資源配置 |
| 營地 | 治療或強化既有裝備 | 當下生存 vs. 後續戰力 |
| Boss | 章節結束與通關獎勵 | 是否有足夠解法處理 Boss 特性 |

### 6.3 地圖生成的硬性條件

- 每個起點到 Boss **至少存在一條可達路線**；不允許斷頭節點與無法選擇的出口。
- 不生成「每條路線都強制連續菁英且無療癒」這類超規範配置。
- 同一個分岔至少應有可辨識的風險／收益差異；不同圖示但最佳選項永遠固定，視為設計失敗。
- `map_seed`、節點與連線可紀錄並還原；圖生成要有大量種子自動驗證。

## 7. 混合式裝備與永久解鎖（採用方案 C）

### 7.1 裝備欄位與用途

| 類別 | 欄位上限 | 是否職業限定 | 作用 |
|---|---:|---|---|
| 武器 | 1 | 是 | 定義瞄準、攻擊方式與主傷害機制 |
| 防具 | 1 | 否 | 防守、移動、地形抗性；以功能差異取代純數值堆疊 |
| 骰印 | 1 | 否 | 操作 D20、低／高骰分支、命運值與效果階級 |
| 遺物 | 2 | 否 | 引發跨系統連鎖，建立流派組合 |

- 首次出發攜帶**已解鎖的 1 把平衡起始武器**，公會解鎖後才能自選 1 個平衡起始骰印。
- 防具及遺物主要在場內取得。進入下一輪時，回復預設起始配置，不能保留上一輪的強力掉落。
- 武器藍圖可以永久解鎖「起始可選變體」或「加入掉落池」；二者須清楚標註，避免誤解為永久持有當輪稀有品質裝備。
- 同一裝備種類可替換而不可無限累加；玩家應有明確換裝確認畫面。

### 7.2 範例裝備效果

| 名稱 | 類型 | 效果（候選） |
|---|---|---|
| 震地戰槌 | 戰士武器 | 定向衝擊；擊退碰撞是主要額外效果 |
| 爆炎法杖 | 法師武器 | 拋物線小範圍爆炸，可破壞薄牆 |
| 寒霜法杖 | 法師武器 | 製造短暫冰面，利用坡度造成滑移 |
| 機關弩 | 盜賊武器 | 精準直射／有限反彈，擅長掩體角度 |
| 鎮地戰甲 | 通用防具 | 降低被擊退距離，但減少機動性 |
| 命運反面鏡 | 骰印 | 每場一次：將數值改為 21 − 原始骰點；**不生成自然 20** |
| 餘燼骰紋 | 骰印 | 原始點數 1–5 時，基礎攻擊附帶小範圍震波 |
| 精密骰心 | 骰印 | 生效點數 6–14 且命中時，強化一次物理互動 |
| 狂亂骰印 | 骰印 | 高階效果強化擊退，但自己也受反作用力 |
| 引信盒 | 通用遺物 | 命中爆炸物或特定薄牆時，引發**最多一次**額外爆炸 |
| 碎岩鈴 | 通用遺物 | 一次攻擊首次破壞平台時，產生定向震波 |
| 反擊扣環 | 通用遺物 | 當次受到擊退後，下一次攻擊獲得有限額外擊退 |

### 7.3 戰鬥獎勵三選一

- 位置 A：保證對目前職業有效的裝備／招式強化。
- 位置 B：可由目前職業使用的通用骰印、防具或遺物。
- 位置 C：相容但較意外的特殊裝備、金幣替代獎勵或轉流派機會。
- 不掉落目前角色永遠無法使用的主武器；所有裝備變更能在選前看到效果對比。
- 使用 `tags`（`knockback`、`explosion`、`terrain`、`low_roll`、`ricochet` 等）引導掉落池，但不保證完整神裝組合。

### 7.4 永久保留與重置

**永久保留**：公會等級、職業解鎖、裝備藍圖、可選起始武器與骰印、成就、外觀與已解鎖章節。

**每輪重置**：拾得裝備、稀有度、遺物、金幣、生命狀態、命運值、路線、敵人與暫時增益。

## 8. 共用公會等級（Meta Progression）

### 8.1 定義

- 只有**公會等級**，不做每個職業獨立 XP。
- 公會 XP 來自冒險進度、Boss 首通、特殊挑戰；失敗也保留合理比例的 XP。
- 解鎖以**橫向選擇**為主，不能無限加攻擊、HP 或初始裝備槽。
- 不應把原本應有的基礎操作功能鎖到高等；新手第一輪就能理解 D20 × 地形擊退。

### 8.2 候選解鎖節點

| 公會等級 | 永久解鎖 |
|---|---|
| Lv.1 | 戰士、法師、預設起始武器；可遊玩完整基礎規則 |
| Lv.2 | 盜賊（待職業玩法通過驗證後才開放） |
| Lv.3 | 第二款起始武器／橫向變體 |
| Lv.4 | 可選一種起始骰印（強度相近的選項） |
| Lv.5 | 擴充遺物與事件池 |
| Lv.6 | 新地形主題與另一種 Boss 機制 |
| Lv.8 | 第二章或高難度詞綴（正式版候選） |
| Lv.10 | 高難度挑戰與純展示性獎勵 |

> 上表只是內容排列候選，不代表首版要製作 Lv.10 或第二章。首個驗證版本只需 Level 1–3，且所有解鎖都需要真人試玩確認有價值。

## 9. 敵人、Boss 與遭遇設計

### 9.1 P0 的敵人

- **近戰哥布林**：顯示下回合移動／衝刺區域，讓玩家練習反向擊退。
- **投石手**：以可見的預告弧線迫使玩家改站位。

### 9.2 Boss 規則

- 第一章 Boss 候選：**礦坑守衛**（大型岩石守衛）。
- Boss 在特殊地形／落坑狀態下受到明顯的**失衡傷害**，但不被一般單次推落直接秒殺。
- 至少有一種非爆破職業也能利用的地形解法；不能硬綁特定武器。
- Boss 攻擊以清楚預告的蓄力和安全區為主，優先理解度而非反應速度。

### 9.3 難度公平性

- 敵人首次釋放關鍵技能前要有提示；避免「敵人一動，玩家就掉坑死亡」卻毫無反制機會。
- 玩家在普通節點即使不拿到關鍵裝備，也應有可行解。
- 戰鬥難度同時觀察回合數、受傷原因、場景可讀性與玩家主觀公平感，不能只看勝率。

## 10. UI、動畫與視覺方向

### 10.1 設計風格

- **主張**：溫暖桌遊微縮模型 + 奇幻地下城 + 可見厚度的地形模組。
- 角色外觀、武器、敵人須原創；參考桌遊質感，不直接臨摹任何遊戲 UI 或角色。
- 優先讓地形高度、可破壞部位、爆炸範圍、敵人意圖一眼看懂。

### 10.2 核心三個畫面

1. **公會畫面**：共用等級、職業切換、起始裝備與開始冒險。
2. **冒險地圖**：分岔路線、節點、地形情報、預期收益與當前生命／裝備。
3. **戰鬥畫面**：同屏看見主戰場、D20、招式、裝備觸發、敵方意圖、DM 預警；避免大量覆蓋戰場的彈窗。

### 10.3 演出優先順序

1. **立即清楚**：攻擊前瞄準、飛行、命中、HP 扣除、地形破裂與角色落點。
2. **有重量感**：擊退前搖、落地彈性、適量畫面震動與音效。
3. **骰子戲劇性**：擲 D20 動畫要短且能跳過；自然 20 有獨立演出但不拖慢每回合。
4. **完整風格統一**：戰場、地圖、公會、物件圖示使用相同材質與描邊邏輯。

減少動態效果（Reduced Motion）、文字可讀性、音量選項及鍵盤操作可達性納入正式版檢查；P0 以清楚灰盒資訊為主。

### 11.3 規則資料與隨機性

- 角色、招式、武器、骰印、遺物以資料驅動表描述（優先 Godot `Resource` / `.tres`，必要時 JSON 匯入），不要把所有效果寫死在 UI。
- 以事件記錄串接：`RollCompleted` → `SkillPrepared` → `ProjectileHit` → `TerrainDamaged` → `DamageResolved` → `TurnEnded`。
- 以獨立 RNG stream 分開**地圖、獎勵、D20、敵人決策**，保存 `run_seed` 與重要抽取紀錄。

### 11.4 存檔

- `guild_save`：版本號、共用 XP／等級、已解鎖職業與藍圖、偏好設定。
- `run_save`：種子、職業、節點與路線、當輪裝備、生命、金幣、當前節點；首版只在節點切換／戰後自動存檔。
- 必須支援向後相容的最低版本檢查；損壞存檔不應覆蓋有效的公會永久紀錄。

### 12.1 三個重大 Go / No-Go Gate

**G1：物理玩具成立（DM-01～DM-03）**
- 玩家可以憑瞄準與位置，在低點數時打出有價值的攻擊。
- 相同場景下 D20 高低改變選擇，而非只是貼上傷害倍率。
- 若核心攻擊仍不好玩，停止擴地圖、裝備與美術，先重做手感。

**G2：流派成立（DM-04～DM-06）**
- 至少一名職業有兩種可辨識打法，並能在地形上展現差別。
- 遺物不會無限連鎖、沒有單一必選裝備、低骰構築可玩。
- 若玩家永遠只選最高傷害，回頭修改裝備而不是增加數量。

**G3：完整一輪成立（DM-07～DM-09）**
- 從公會→選路→戰鬥→獎勵→Boss→死亡／通關→公會可完整循環。
- 5 名目標玩家試玩：至少 4 人能在不受引導下理解敵人及事件預警；至少 3 人願意改用不同構築再玩一輪（**候選門檻，非已測數據**）。
- 若只有第一輪新鮮但第二輪無差異，延後擴內容與 Steam 頁面。

## 13. 測試矩陣與驗收證據

### 13.1 單元與性質測試

- D20 原始點數永遠 1–20；強制點數注入可覆蓋四階。
- `raw_roll != 20` 時，任何修正、反面鏡或重擲效果都不得冒充原骰自然 20；若真的重新擲出原始 20，才算自然 20。
- 命運值不能低於 0、高於上限；只在該回合結束後發給低骰者。
- 每個裝備效果單次攻擊觸發次數不超過合約，事件遞迴能終止。
- 每次死亡：`guild_save` 正確保留，`run_save` 正確重置；職業切換不重置公會 XP。
- 批量地圖種子測試：所有生成路線皆可抵達 Boss、無空節點、無重複異常連線。

### 13.2 場景與物理測試

- 拋射物不穿過主要地面；破壞平台後碰撞確實移除或切換。
- 角色不會無限彈跳、卡在平台碎片、同一撞擊扣血多次。
- 崩塌事件至少提前一回合預告，預警圖示與實際判定範圍一致。
- Boss／一般敵人的落坑規則一致且 UI 有明示差異。
- 各職業相同物件位置下的技能差異可以用可重複的測試場景檢視。

### 13.3 人工試玩

- 不先講解，讓玩家實際操作：是否知道去哪看 D20、如何瞄準、哪裡會塌陷？
- 記錄「玩家試圖做什麼、實際發生什麼、為何失敗、是否知道如何修正」。
- 選路測試時需同時記錄**職業／裝備／生命／路線選擇原因**，否則無法判定分岔有沒有策略價值。
- 視覺驗收一定要以**執行畫面錄製／真實操作**為準；不能用靜態概念圖代替可玩性。

### 13.4 每個 Draft PR 的完成證據

- 範圍與不在範圍項目、head commit、變更清單、風險。
- Headless 規則測試結果、引擎版本、手動場景測試。
- 對操作／視覺 Slice 提供原生影片與代表畫面；標註模擬／實機、是否為後製聲音。
- Windows 可執行測試包（若該 Slice 需要）、其 SHA-256 與安裝／啟動驗證。
- **分開紀錄**：已完成、送審、Owner 已接受但待驗證、已知待處理債務；不可用「測試過」替代發布核准。

## 20. 主動反證與停損實驗（實作前先同意）

### 20.1 D20 是否真的提升樂趣？

使用同一張地圖與同一名角色，比較：

- **A 組：無 D20**，所有招式固定為中階效果。
- **B 組：有 D20**，玩家在攻擊前看到擲骰結果，可使用命運值。

受測者不是只回答「骰子好不好看」，而要記錄：是否改變移動路線、瞄準位置、物件優先序；若 B 組只增加等待和挫折，先縮減骰子演出或改造效果，不應繼續堆裝備。

### 20.2 一名角色是否足以支撐一輪？

原案已確認**每輪只帶一個職業**，這是產品決定。但應量測每回合耗時與敵人回合占比；如果玩家等待敵人動畫多於做出有意義選擇的時間，優先減少敵人行動回合、合併敵人解算與加速演出，而不是擴成三人小隊。

### 20.3 地圖分岔是否只是表面選擇？

至少安排兩種截然不同的當輪構築，記錄兩者如何選擇相同的兩條路。若兩者總選同一路線，不增加節點數，先增加**地形資訊、風險差別及補給取捨**。

### 20.4 Roguelite 與地形破壞是否互相衝突？

如果某件裝備可以把每場戰鬥變成「開場直接炸掉所有支柱」，導致地形解題消失，先限制觸發機會、改變敵人站位或增加受保護的地形關鍵點，而非全面強化敵人 HP。
