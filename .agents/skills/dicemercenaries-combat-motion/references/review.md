# 比較與交付

固定場景、尺寸、鏡頭、玩家站位、角度／力度與輸入，比正常速度前後版本。先看全戰場再放大，保有危險、HP、第一撞點及可操作狀態。

核對正常／降低動態的collider、HP、模組狀態、命中次數及落地結果；Godot物理不保證跨平台逐影格一致，使用事件及容許範圍。保護取消、射偏、重複碰撞、空間邊界、破壞中重置、案例切換、快速輸入及連鎖終止。

記錄Godot版本、commit／dirty state、viewport、素材／anchor／timing和拍攝方式。錄影腳本不是人類鍵鼠試玩，Windows headless不是桌面顯示品質，UI模擬不是原生動畫。音訊波形／排程不能證明實際喇叭同步。

每輪處理一個可指出的差距，以相同資料比較候選；沒有改善就留最佳稿並換假設。角色手勢、接觸拍點、布料收尾可提出比較，但不能從競品動畫數字改寫物理時序。

使用「改善／持平／退步／未檢查」加具體影音理由，不加總成市場分數。sprite、全套音效、相機及批量角色依當次授權；當前切片失敗先修，視覺文件不越過未接受G1。
